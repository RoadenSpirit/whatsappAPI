## REGLA INNEGOCIABLE DE REQUISITOS (TODO LIST)

Cada vez que trabajes en este proyecto, debes crear o actualizar un archivo llamado `requisitos.md` en la raíz del proyecto.
- En este archivo se debe dejar constancia de cada cambio importante planificado y aprobado.
- Se deben ir marcando con una `[x]` las tareas completadas y con `[ ]` las pendientes.
- El usuario debe poder ver en cualquier momento qué features se han terminado y cuáles quedan pendientes por hacer.
- Estructura el archivo en secciones claras como "Características Pendientes" y "Características Completadas".
